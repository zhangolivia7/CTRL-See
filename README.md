# CTRL-See
CTRL-See is a Chrome extension that saves your copy history for you in a popup. Simply copy text as you usually do and retrace your history, copy, or delete items directly from the extension quickly and effortlessly.
![Untitled design](https://github.com/user-attachments/assets/db13c683-51c2-43d7-abab-32f90d2fd32f)

### How to Use
While the official Chrome Extension is in the verification process, here's how you can use the extension for now:
1. Download the contents of this project.
2. Copy the following address into your search bar: `chrome://extensions/`
![image](https://github.com/user-attachments/assets/0c0a38c6-e2bb-48b6-b1a2-ac261b0c0faa)
3. Click on `Load Unpacked` at the top left corner.                                  
  ![image](https://github.com/user-attachments/assets/be86b06e-752c-4135-93a4-d5d05fb1b480)
4. When you're prompted to select a folder, navigate to wherever you saved this project and select that folder.
5. Enjoy!
